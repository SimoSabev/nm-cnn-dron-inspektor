# Работа в екип и в GitHub

## 1. Начална настройка (Ръководител, до 02.12.2026)

1. Създайте хранилище `nm-cnn-dron-<екип>` в GitHub и качете тази папка.
2. *Settings → Collaborators* → добавете учителя и членовете на екипа.
3. В първата клетка на всяка тетрадка сменете `REPO_URL` с адреса на хранилището.
4. Попълнете таблицата „Екип“ в `README.md`.
5. Създайте задачите по-долу като **Issues** с отговорник (*Assignees*) и етикет (`НМ`, `АСД`, `ЕМП`, `интеграция`).

> ⚠️ Приносът на всеки се вижда в *Insights → Contributors* и в историята на commits – оценява се. **Всеки качва своята част от свой акаунт.** Не качвайте всичко от един човек.

## 2. Клонове и pull requests

```bash
git checkout -b asd/rekursivno-obhojdane      # свой клон за задачата
# ... работа ...
git add src/grid_zones.py tests/test_grid_zones.py
git commit -m "Добавено рекурсивно обхождане на зоните с пукнатини"
git push -u origin asd/rekursivno-obhojdane
```
После в GitHub: *Compare & pull request* → **друг член на екипа** преглежда и одобрява → *Merge*.

**Добри съобщения:** „Добавен flood fill за зоните с пукнатини“, „Праг по пълнота ≥ 99 % върху валидационното“, „ГА: кръстосване OX и мутация с обръщане“.
**Лоши:** „update“, „fix“, „asdf“, „final2“.

## 4. Защита – какво трябва да може да обясни ВСЕКИ

Ролите разпределят отговорността, не знанието. Примерни въпроси към всеки участник:

**НМ**
- Какво прави конволюционният слой? Колко параметъра има Conv 3×3 с 32 → 64 канала? *(3·3·32·64 + 64 = 18 496; без bias при BN – 18 432)*
- Защо сигмоида на изхода и бинарна кросентропия?
- Какво е трансферно обучение и защо при финото настройване скоростта е 10⁻⁵?
- Защо прагът не е 0.5? Какво е пълнота и защо е важна тук?
- Защо тестовото множество се ползва само веднъж?

**АСД**
- Кои са дъната на рекурсията във `_fill`? Какво става, ако махнем проверката за посетена клетка?
- Защо обхождането е O(R·C), а не O((R·C)²)?
- Каква е разликата между 4- и 8-свързаност и коя ползваме?
- Защо сортирането чрез сливане е O(n log n) и стабилно?

**ЕМП**
- Защо задачата е NP-трудна? (при безкрайна батерия е задачата за пътуващия търговец)
- Как най-близкият съсед спазва батерията? Къде греши и защо?
- Как е представена хромозомата? Защо OX дава винаги валидна пермутация?
- Защо точното решение (пермутации + split) наистина е оптимално? Каква е сложността му?

**Конвейер**
- Какво е входът и изходът на всяка част? (виж `docs/arhitektura.md`, раздел 3)
- Как се превръщат зоните (редове/колони) в точки в метри?
- Какво става в конвейера, ако CNN пропусне една плочка от средата на пукнатина? *(зоната се разделя на две → една точка повече в маршрута)*
